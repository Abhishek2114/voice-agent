## What is covered

### Engine (`tests/unit`)

- **Audio:** WAV round-trip, resampling, RMS, recorder writes a private (0600) stereo WAV.
- **VAD and turn detection:** speech segmentation, short-click rejection and maximum utterance length (energy VAD).
  Silero rejects silence and detects real speech generated by macOS `say` (skipped where `say` is unavailable).
- **Conversation:** speech cleanup and sentence streaming; guardrails in the system prompt; strict tool-argument
  validation; refusal of unpermitted tools; tool execution (callback, opt-out ends the call, lead capture); per-turn
  knowledge retrieval that is not persisted; isolation between sessions; end phrases; LLM failure propagation.
- **Outcome analysis:** deterministic overrides (opt-out, wrong number, no answer), LLM classification, and an error
  reported instead of a guessed outcome.
- **Voice pipeline:** a full turn; barge-in that cuts audio and records only the sentences actually heard; the manual
  interrupt button; silence re-prompt then hang-up; maximum duration; LLM failure that speaks a fallback and ends;
  recoverable STT failure; the agent ending the call; mute; idempotent stop with task cleanup; AI-slot backpressure
  ("waiting" state).
- **Provider adapters against mocked HTTP:**
  - Ollama: discovery, cloud-model detection and refusal, streaming, `think=false`, tool calls, connection errors,
    JSON mode.
  - whisper-server and Piper.
  - Simulator: determinism and validation.
  - RTP: codec, and rejection of packets from other hosts or SSRCs.
  - Asterisk ARI: config validation, health, bad credentials, dial-to-busy mapping, events URL.
  - WebRTC offers that contain video are rejected.

### Backend (`backend/tests`)

- **Auth:** first-run setup happens only once; weak passwords are rejected; login and logout; the same error for
  unknown users; rate limiting (429 even with the right password while locked); CSRF required on every mutation;
  cross-origin mutations refused; untrusted Host refused; unauthenticated access blocked; a password change revokes
  other sessions; deactivated users lose access.
- **Workspaces:** CRUD and validation; role enforcement (a viewer cannot write); editors cannot escalate; the last
  owner is protected; compliance-policy validation; export/import round trip; garbage imports rejected; soft delete.
- **Contacts and imports:** phone normalisation; formula detection and escaping; CRUD, search, filters, tags, custom
  fields, duplicates, history; erasure keeps the suppression entry. The full CSV workflow covers mapping guesses,
  invalid and duplicate rows, formula neutralisation, consent recorded only with evidence, and raw-file deletion.
  Upload validation rejects executables, binary data, empty files, duplicate headers, files over 10 MB and bad
  mappings.
- **Knowledge and agents:** chunking; FTS query sanitising; FAQ, Markdown and PDF upload and search; deletion removes
  the document from the index; bad files are rejected. Agents: version history, restore and duplicate; validation;
  remote models refused; the test console works with a real session and reports an LLM outage as 503.
- **Compliance and campaigns:**
  - Calling-window maths and policy validation.
  - Eligibility fails closed: no consent, DND unknown, DND registered, a stale scrub, opt-out, frequency per mode,
    expired consent and missing PSTN prerequisites all block.
  - A simulation campaign runs end to end through the scheduler.
  - The concurrency limit is respected, and dedupe keys are unique.
  - Restart recovery: interrupted calls are marked, there are no duplicate jobs, and the campaign completes.
  - A second scheduler is refused.
  - Outside the window, contacts wait; pause, resume and cancel work.
  - PSTN campaigns are refused by default.
  - A provider outage auto-pauses the campaign without burning contact attempts.
- **Calls and system:**
  - A simulated call produces a transcript, summary and outcome, and never changes real contact status.
  - Simulated inbound calls work.
  - Lead capture from a real conversation: dedupe, consent linked to the call.
  - An opt-out during a real call suppresses the number.
  - Callback flow; analytics computed from records.
  - System health; SSRF rejection on provider URLs; secrets never echoed back.
  - Backup: create, verify, encrypted, wrong passphrase, tampering, path traversal, stage and apply restore.
- **Sample workspace:** imports exactly as documented and contains no price figures.

### Security (`tests/security`)

Cross-workspace isolation:

- every read endpoint returns 404 for another workspace;
- foreign IDs used through your own workspace path return 404 for reads, writes, simulations, campaigns, consent
  and voice sessions;
- knowledge search is scoped to the workspace;
- transcripts are not searchable across workspaces;
- a client-supplied `workspace_id` in the request body is ignored.

Web security:

- SQL-injection payloads in every filter are inert;
- an XSS payload is stored as data and served as JSON with a strict CSP;
- security headers; CORS allows only the dashboard origin;
- malformed and oversized requests are rejected;
- logo content sniffing blocks SVG/JS disguised as PNG and path tricks;
- public-link lifecycle: no identifier leaks, rate limiting, disabled links return 404;
- the SSRF validator; log redaction.

### Integration (`tests/integration`)

- **Real WebRTC:** an aiortc peer standing in for the browser negotiates through the API, streams audio, receives
  synthesised agent audio and data-channel events, and the call is stored with metrics. The tests also cover
  pre-flight "model not installed" and capacity limits.
- **Real models:** Ollama discovery and cloud refusal; Piper → whisper.cpp round trip; the full pipeline with
  Silero, whisper.cpp, Qwen3 4B and Piper on synthesised caller speech.

### Dashboard (`apps/dashboard/src/**/__tests__`)

- Formatting helpers.
- The API client: query strings, error parsing for 401/422/404/502, network errors, CSRF header on mutations only.
- Zod schemas.
- Shared components: mode badge with simulation hatch, outcome badges, pagination, error state, field errors.
- Navigation: hrefs, `aria-current`, redirect on 401 and for foreign workspaces.
- Login form validation and server errors.
- A data page's error, retry and loading states.

### Browser end-to-end (`apps/dashboard/e2e`)

Runs against an **isolated instance**: a temporary data directory, API on :8100 with its own scheduler, and the
dashboard on :3100. It uses the installed Google Chrome. The fake microphone plays speech synthesised by Piper, so
the voice test exercises the real local models.

1. First-run setup with validation errors.
2. Wrong password, then sign-in.
3. Create an agent, then chat with it on the local model.
4. **Live voice conversation:** the greeting with AI disclosure is spoken; the caller's speech is transcribed and
   answered; ending the call leads to the stored call record.
5. Contacts: phone validation, then the CSV import wizard.
6. A simulation campaign started from the UI and completed by the scheduler.
7. Analytics table view, AI-model settings and diagnostics.
8. Unauthenticated access is blocked.
9. (Optional, `CAPTURE_SCREENSHOTS=1`) the README screenshots.

## Known limitations of the test suite

- Real PSTN calling is tested only against a mocked Asterisk ARI server. It has not been tested against a live
  carrier.
- The Chrome fake microphone plays a fixed file in a loop, so the E2E voice test asserts that the conversation
  happens, not specific model wording.
- While the latency benchmark was running in parallel (CPU saturated), five scheduler tests timed out once. The
  same suite then passed twice in a row on an otherwise idle machine. Run the suite while the machine is not under
  heavy load.
- Browser support was verified in Chrome only (Playwright `channel: chrome`). Safari and Firefox were not tested
  automatically.

## Running the tests

```bash
make test            # pytest + vitest
make test-real       # real local models (start the stack first)
make test-e2e        # Playwright; needs Ollama, whisper-server and Piper running
make lint typecheck  # ruff, eslint, mypy, tsc
make security        # bandit, pip-audit, npm audit, gitleaks
```
